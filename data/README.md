# Data

## External Dataset

This project uses the [Fantasy-Premier-League](https://github.com/vaastav/Fantasy-Premier-League) dataset by vaastav.

To set up data locally:

```bash
git clone https://github.com/vaastav/Fantasy-Premier-League.git data/Fantasy-Premier-League
```

## Generated Datasets

The following datasets are generated by the notebooks and not tracked in Git:

- `timeseries_dataset.csv` - Generated by `notebooks/02_feature_engineering.ipynb`
- `all_players_timeseries_dataset.csv` - Full player time series data
- `merged_seasons.csv` - Multi-season merged data
- `predictions.csv` - Model prediction outputs

## Understat Data

Advanced statistics (xG, xA) are scraped from [Understat](https://understat.com/) using `src/data_collection/understat.py`.
